# SCAMPER 매트릭스 튜토리얼 카탈로그 (A4 · 8페이지)

사장님을 위한 SCAMPER 매트릭스 튜토리얼 소개 카탈로그입니다.

- `SCAMPER Tutorial Catalog.dc.html` : 카탈로그 원본 (doc-page / image-slot 컴포넌트, Industry 디자인 시스템 `_ds/`)
- `SCAMPER Tutorial Catalog.pdf` : 인쇄·배포용 PDF (GIF는 대표 프레임으로 출력)
- `assets-scamper/` : 공개 사이트·씽킹 매트릭스 화면 캡처, GIF 2종(3분 체험 흐름 · 업종 탭), 튜토리얼 QR

화면은 공개 사이트(devlog.moonlang.com/scamper-tutorial)와 씽킹 매트릭스(devlog.moonlang.com/scamper-matrix)를 직접 조작해 캡처했습니다. 가게 이름과 점수는 튜토리얼과 같은 설명용 가상 예시입니다.

## 미리보기

```bash
cd docs/catalog
python -m http.server 8099
# http://localhost:8099/SCAMPER%20Tutorial%20Catalog.dc.html
```
