🌷 ‘보라꽃방’ 꽃집

목표: 평일 매출 올리기 — SCAMPER 7가지 질문으로 아이디어 9개를 정리했습니다.

핵심 3가지

S 대체 현장 결제 대신 카톡 주문·퀵 배송 → 전화를 못 받아 놓치던 주문 회수
A 응용 넷플릭스식 월 구독 꽃 배달 → 평일에도 고정 매출
P 전용 시든 꽃 → 드라이플라워 리스 → 폐기 비용이 신상품으로

    효과 4 · 실현 3

    효과 4 · 실현 3

먼저 시작하기 좋은 것 (5개)

  1. 대체 현장 결제 대신 카톡 주문·퀵 배송 — 전화 주문 놓치지 않기
  2. 결합 꽃 + 케이크 셋트 (옆 베이커리) — 기념일 패키지
  3. 결합 꽃 + 원데이 클래스 결합 — 수강료 + 꽃다발 증정
  4. 응용 구독 서비스 응용 — 월 1회 꽃 배달 — 넷플릭스식 정기 결제
  5. 전용 시든 꽃으로 드라이플라워 리스 — 폐기 꽃을 새 상품으로
